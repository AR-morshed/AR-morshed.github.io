06 — AI-native engineeringAI proposes. Engineers decide.

Built with AI,owned by engineers.

I work in the AI-Driven Development Lifecycle (AI-DLC). AI agents plan, ask questions and write code in short bolts. I review, decide and own what ships. Pick a phase to watch a session.

ai-dlc · inceptionlive
Example session · sample feature
Bolts, not sprints. Work moves in cycles of hours or days, with a human checkpoint at the end of each one.

What AI does

  • Breaks intent into stories and units of work
  • Asks clarifying questions before building
  • Drafts code, tests and docs in small diffs
  • Summarises crashes, logs and release notes

What I do

  • Set the architecture and the rules
  • Approve plans before any code is written
  • Review every change, own what ships
  • Decide trade-offs with product and the team

AI project setup

Projects that AI understands from the first prompt.

I set up repositories so agents follow the same architecture and conventions as the team: context files, coding rules, reusable prompts and skills, and tool connections to docs, tickets and CI. Plans and decisions live in the repo, so context carries from one session to the next.
